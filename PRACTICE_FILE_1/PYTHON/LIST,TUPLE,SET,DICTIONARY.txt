# Question:
# Write a Python program to take multiple user inputs in comma-separated format,
# store them as lists inside another list, and display each user's details.

f = []  # List to store all user details

for i in range(5):
    data = input("Enter your details separated by comma (name,address,city,state): ")
    s = data.split(",")  # Split input string into a list
    f.append(s)          # Append the list to the main list

# Display each user's details
print("user details 1:", f[0])
print("user details 2:", f[1])
print("user details 3:", f[2])
print("user details 4:", f[3])
print("user details 5:", f[4])

# Comment:
# This program demonstrates:
# - Taking multiple comma-separated inputs from the user
# - Using split() to convert input string into a list
# - Storing each user's details as a sublist in a main list
# - Accessing and printing each sublist using indexing
# - Maintaining order of entry for easy reference
