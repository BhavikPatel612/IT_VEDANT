# Question:
# Write a Python program to demonstrate all basic arithmetic operations between two numbers.

#Arithmetic operator
a=6
b=10
print ("Subtraction    :",a-b)
print ("Addition       :",a+b)
print ("Multiplication :",a*b)
print ("Division       :",a/b)
print ("Modulus        :",a%b)
print ("Exponention    :",a**b)
print ("Floor division :",a//b)

# Comment:
# This program shows how Python performs arithmetic operations between two numbers.
# - Subtraction (-) subtracts b from a
# - Addition (+) adds a and b
# - Multiplication (*) multiplies a and b
# - Division (/) divides a by b and returns a float
# - Modulus (%) gives the remainder of a divided by b
# - Exponentiation (**) raises a to the power of b
# - Floor division (//) divides a by b and returns the integer part only

# Question:
# Write a Python program to demonstrate logical operators (and, or, not) between two numbers.

# Program:
# Logical operator example

a=5
b=5
print (a>=b and a==b)
print (a>b or a==b)
print (not(a>=b and a==b))


# Comment:
# Logical operators combine boolean expressions:
# - 'and' returns True only if both conditions are True
# - 'or' returns True if at least one condition is True
# - 'not' negates the boolean value of the condition
# Here, the program checks different combinations of comparisons between a and b.

# Question:
# Write a Python program to demonstrate bitwise operators (&, |, ^) between two numbers.

a=10
b=8
print (a & b)  # Bitwise AND: 1 if both bits are 1
print (a | b)   # Bitwise OR: 1 if at least one bit is 1
print (a ^ b)  # Bitwise XOR: 1 if bits are different
